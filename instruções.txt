# 📌 CONTEXTO COMPLETO DO PROJETO — ArenaRift

## 🧠 VISÃO GERAL DO PROJETO

O projeto é um site chamado **ArenaRift**, focado em campeonatos competitivos de *Wild Rift*.

A ideia principal é:

* Permitir que jogadores participem de campeonatos online
* Criar uma experiência competitiva com progressão (fases, ranking, etc.)
* Centralizar tudo em uma plataforma simples e visualmente atrativa

O diferencial do projeto é:

👉 Login obrigatório com Discord
👉 Foco total em experiência gamer competitiva
👉 Interface moderna (dark, neon, minimalista)

---

## 🎯 OBJETIVO DO MVP (VERSÃO INICIAL)

Criar uma versão funcional mínima onde o usuário pode:

* Entrar com Discord
* Visualizar campeonatos
* Se inscrever em campeonatos
* Ter um perfil básico

Sem funcionalidades avançadas inicialmente.

---

## 🧑‍💻 STACK UTILIZADA

* Front-end: React + Next.js
* Estilização: Tailwind CSS
* Linguagem: TypeScript (nível básico)
* Componentização: baseada em componentes reutilizáveis
* API: ainda não implementada
* Autenticação: planejada com Discord OAuth (provavelmente NextAuth)
